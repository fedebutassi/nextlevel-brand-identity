# Carrusel — Señales de rediseño

## Objetivo

Ayudar a un negocio a reconocer problemas comunes de su web sin utilizar estadísticas no verificadas.

## Secuencia

1. Portada: cinco señales de que una web necesita un rediseño.
2. Carga lenta.
3. Problemas en dispositivos móviles.
4. Estructura difícil de interpretar para buscadores.
5. Percepción visual desactualizada.
6. Falta de un camino claro hacia el contacto.
7. Cierre con CTA a Instagram y referencia web.

## Producción

- Tamaño: 1080×1350.
- Fuentes: `fonts/` en la raíz del repositorio.
- Logo: contenido vectorial derivado exclusivamente de `assets/logo.svg`.
- `source/`: SVG editables.
- `exports/`: PNG aprobados.

No agregar etiquetas sobre los títulos ni introducir cifras sin cumplir `CLAIMS_POLICY.md`.
