# Caption — Una web no termina al publicarse

Publicar una web no es marcar una tarea como terminada. Es poner una herramienta a trabajar.

El negocio cambia. Aparecen nuevos servicios, trabajos y preguntas. La tecnología también necesita revisión.

Mantener una web es conservarla clara, útil y alineada con lo que hoy necesita tu negocio.

Construimos productos digitales que duran.
