# Reel — ¿Qué encuentra un cliente?

Reel comercial orientado a vender desarrollo web a partir de una situación cotidiana: un potencial cliente busca el negocio y evalúa lo que encuentra.

- Formato: 1080×1920.
- Duración: 19 segundos.
- Frecuencia: 30 fps.
- Audio: sin pista, preparado para música desde Instagram.
- CTA: `nextlvl.com.ar`.
- Zona segura aplicada: 90 px izquierda, 180 px derecha, 190 px arriba y 350 px abajo.

Las medidas de seguridad son una decisión conservadora basada en la recomendación de Meta de mantener elementos clave fuera de las áreas cubiertas por la interfaz.
