# Revisión editorial de reels

## Criterio

Cada reel debe ocupar un ángulo reconocible dentro del sistema de contenido. Puede compartir el servicio principal —desarrollo web— pero no repetir el mismo argumento, secuencia o beneficio central.

## Serie actual

| Reel | Pilar | Idea central | Diferencia |
|---|---|---|---|
| Tu web debería vender con vos | Conversión | La web acompaña el proceso comercial | Se enfoca en consultas y acción |
| Tu web no es un catálogo | Posicionamiento | Una web es una herramienta con propósito | Se enfoca en la función general del sitio |
| Instagram y tu web | Posicionamiento | Redes y sitio cumplen papeles distintos | Compara canales y propone usarlos juntos |
| Qué incluye una web a medida | Servicio | Componentes del trabajo personalizado | Explica qué se contrata |
| Tu web en el celular | Educación | Diseñar móvil requiere decisiones propias | Se enfoca en legibilidad, navegación y controles |
| Cómo mostrar un proyecto web | Autoridad | Un caso explica problema, decisiones y resultado | Enseña a comunicar trabajo y criterio |
| Antes de pedir presupuesto | Conversión | Información mínima para iniciar un proyecto | Reduce fricción antes de consultar |
| Una web no termina al publicarse | Autoridad | El producto necesita mantenimiento | Se enfoca en la etapa posterior al lanzamiento |

## Cambio realizado

Se retiró “La primera pantalla de tu web” porque repetía claridad, propuesta y próximo paso —ideas ya cubiertas por “Tu web debería vender con vos” y “Tu web no es un catálogo”. Se reemplazó por “Cómo mostrar un proyecto web”, que incorpora el pilar de casos y autoridad.
