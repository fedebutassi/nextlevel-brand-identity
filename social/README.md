# Recursos para redes

Esta carpeta contiene piezas aprobadas que funcionan como referencia de producción.

## Convención de una plantilla

```text
nombre-de-la-pieza/
  README.md       Objetivo, copy y reglas específicas
  source/         Archivos editables
  exports/        PNG finales en tamaño de publicación
```

Las exportaciones sirven para revisión y publicación. Los cambios deben realizarse siempre sobre los archivos de `source/`.
