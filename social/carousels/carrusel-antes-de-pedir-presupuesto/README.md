# ANTES DEL PRESUPUESTO

## Secuencia

1. **Antes de pedir presupuesto para una web.**  
   Definí estas seis cosas.
2. **¿Qué tiene que lograr?**  
   El objetivo permite priorizar alcance y decisiones.
3. **¿Para quién la construimos?**  
   El diseño cambia cuando cambia la persona que la usa.
4. **¿Qué tiene que contar?**  
   El contenido define la estructura antes que las pantallas.
5. **¿Qué tiene que poder hacer?**  
   Informar no es lo mismo que vender o gestionar.
6. **Mostrá lo que te representa.**  
   Una referencia sirve más cuando explicás por qué.
7. **Primero, lo importante.**  
   Una prioridad clara ayuda a construir un alcance real.
8. **Una idea clara. Un alcance real.**  
   Nosotros te ayudamos a ordenar el resto.
