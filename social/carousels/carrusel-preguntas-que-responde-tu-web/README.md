## Secuencia

1. **Tu web debería responder esto.**  
   Antes de que el cliente tenga que escribirte.
2. **¿Qué hacés, exactamente?**  
   La propuesta principal no puede quedar implícita.
3. **El cliente tiene que reconocerse.**  
   Cuando cambia el público, también cambia el mensaje.
4. **¿Por qué elegirte a vos?**  
   La diferencia tiene que ser concreta y demostrable.
5. **Mostrá cómo trabajás.**  
   Un proceso visible reduce dudas antes de empezar.
6. **No alcanza con decirlo.**  
   Los trabajos reales sostienen la promesa.
7. **¿Cómo seguimos?**  
   Una acción clara evita que el recorrido termine en duda.
8. **Menos dudas. Un paso claro.**  
   ¿Tu web responde estas preguntas?
