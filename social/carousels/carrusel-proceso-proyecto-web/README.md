## Secuencia

1. **De una idea a una web publicada.**  
   Seis etapas. Un proceso claro.
2. **Primero, entender el negocio.**  
   Las decisiones empiezan en una conversación real.
3. **La idea se convierte en alcance.**  
   Objetivos, contenido y funciones dejan de estar mezclados.

   La publicación necesita más que apretar un botón.
7. **Después, seguimos cerca.**  
   La entrega no termina cuando la web sale online.
8. **Un proceso claro. Sin sorpresas.**
