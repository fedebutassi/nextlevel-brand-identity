# LANDING O SITIO WEB

## Secuencia

1. **¿Landing page o sitio web?**  
   La respuesta depende del recorrido que necesitás construir.
2. **Una landing tiene un objetivo central.**  
   Presenta una propuesta y guía hacia una acción concreta.
3. **Funciona bien para una campaña.**  
   Un lanzamiento, un servicio puntual o una captación específica.
4. **Un sitio organiza más información.**  
   Servicios, casos, empresa, preguntas y contacto tienen su espacio.
5. **Funciona mejor para una presencia estable.**  
   El cliente puede explorar, comparar y volver cuando lo necesite.
6. **No elijas por cantidad de páginas.**  
   Elegí según el objetivo, el contenido y la decisión del cliente.
7. **Primero el problema. Después la herramienta.**  
   Contanos qué necesitás en @nextlvl.ok
