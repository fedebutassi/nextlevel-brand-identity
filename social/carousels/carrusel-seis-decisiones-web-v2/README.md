# UNA WEB A MEDIDA

## Secuencia

1. **Tu web no empieza por el diseño.**  
   Empieza por seis decisiones conectadas.
2. **Primero: qué tiene que lograr.**  
   Una prioridad clara ordena todo lo que viene después.
3. **Después: decirlo claro.**  
   Si el cliente tiene que interpretar demasiado, el diseño no puede salvarlo.
4. **Que se vea bien no alcanza.**  
   La marca aparece en cómo se ordena, se lee y se siente cada pantalla.
5. **Cada pantalla tiene un trabajo.**  
   El recorrido acompaña la decisión del cliente, no la complica.
6. **Lo que no se ve también importa.**  
   Una base prolija evita que cada cambio se convierta en un parche.
7. **Publicar no es terminar.**  
   Medir, escuchar y ajustar mantiene la web alineada con el negocio.
8. **Todo conectado. Hecho a medida.**  
   ¿Estás por crear o rediseñar tu web?

## Caption

Una web no empieza eligiendo colores.
