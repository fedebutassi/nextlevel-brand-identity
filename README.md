# nextlevel. — Brand & Content System

Repositorio oficial de identidad y producción de contenido de **nextlevel.**

Este repositorio es la fuente única de verdad para cualquier pieza visual, texto, publicación, historia, carrusel o reel. Antes de producir contenido nuevo se deben consultar los documentos correspondientes y reutilizar los activos y plantillas existentes.

## Inicio rápido

1. Leer `BRAND_OVERVIEW.md` para entender la marca.
2. Aplicar `COLORS.md`, `TYPOGRAPHY.md`, `LOGO.md` y `VISUAL_STYLE.md`.
3. Escribir según `VOICE_AND_TONE.md`.
4. Para redes, seguir `SOCIAL_CONTENT.md` y `CLAIMS_POLICY.md`.
5. Reutilizar las fuentes de `fonts/`, el logo de `assets/` y las plantillas de `social/templates/`.

## Estructura

```text
assets/          Logos e imágenes oficiales
fonts/           Fuentes estáticas aprobadas
social/          Plantillas, fuentes editables y exportaciones de referencia
*.md             Lineamientos de marca, contenido y producción
```

## Operación comercial

- `CONTENT_STRATEGY.md`: objetivo, audiencia, funnel, pilares y decisiones estratégicas.
- `COMMERCIAL_OPERATIONS.md`: oferta inicial, alcance, CTA, calificación y medición.
- `LEADS_REGISTER.md`: registro interno de oportunidades sin datos personales.
- `CLAIMS_POLICY.md` y `CLAIMS_REGISTER.md`: control obligatorio de cifras, comparaciones y resultados publicables.

Toda pieza debe sentirse editorial, cálida, directa y deliberada. No se agregan tipografías, colores, estadísticas, efectos o estructuras ajenas al sistema sin documentar previamente la decisión.
