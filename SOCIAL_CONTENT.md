# Sistema de contenido para redes

## Objetivo

Crear contenido reconocible como nextlevel. incluso antes de ver el logo. Las piezas deben explicar, demostrar o invitar a actuar; nunca llenar espacio por obligación.

## Formatos

| Uso | Tamaño | Relación |
|---|---:|---:|
| Feed vertical | 1080×1350 | 4:5 |
| Stories | 1080×1920 | 9:16 |
| Reels | 1080×1920 | 9:16 |
| Feed cuadrado excepcional | 1080×1080 | 1:1 |

Toda publicación individual o pieza destinada a stories debe producirse, cuando el contenido lo permita, en dos versiones: feed 1080×1350 y story 1080×1920. No se estira una versión para obtener la otra; se recompone.

## Tipografía

- Títulos: Bricolage Grotesque Condensed Bold.
- Subtítulos: Bricolage Grotesque Condensed SemiBold.
- Texto secundario: Bricolage Grotesque Condensed ExtraLight.
- Bricolage Grotesque nunca se utiliza en cursiva o estilo italic.
- JetBrains Mono queda reservado para numeración, navegación, captions pequeños y metadatos.
- No se utilizan etiquetas, eyebrows o categorías flotando sobre los títulos salvo que cumplan una función indispensable.
- No se sustituyen las fuentes oficiales por aproximaciones del sistema.

## Logo

- Usar siempre `assets/logo.svg` como fuente oficial.
- Nunca reconstruir el logotipo escribiendo “nextlevel.” como texto independiente.
- El punto es obligatorio.
- Mantener el área de seguridad indicada en `LOGO.md`.

## Composición

- Fondo principal: Paper `#F1E8D8`.
- Texto principal: Ink `#1A1410`.
- Terracota `#D24322` solo para énfasis y CTA.
- Usar espacio negativo generoso y títulos contundentes.
- Mantener márgenes seguros mínimos de 64 px en feed y 72 px en stories.
- Ningún texto puede quedar cortado, fuera del lienzo o debajo de controles de Instagram.
- Evitar adornos que no ayuden a comprender el mensaje.

## Pilares de contenido

1. Educación: decisiones prácticas sobre diseño, web, SEO y rendimiento.
2. Autoridad: procesos, criterios de trabajo y decisiones técnicas explicadas con claridad.
3. Casos: problema real, trabajo realizado y resultado comprobable.
4. Posicionamiento: por qué una presencia digital propia importa para un negocio.
5. Conversión: invitaciones concretas a conversar o conocer un servicio.

## Carruseles

- Entre 5 y 8 diapositivas.
- La portada debe prometer una idea clara, no presentar una categoría.
- Una idea principal por diapositiva.
- El cierre debe resumir el beneficio y ofrecer un único CTA.
- La numeración puede funcionar como recurso visual.
- Revisar continuidad, ritmo y legibilidad a tamaño móvil.

### Referencia aprobada

`social/carousels/carrusel-seis-decisiones-web-v2/` es la referencia principal para producir nuevos carruseles de nextlevel.

Usarlo como referencia no significa replicar su plantilla. Cada temática debe proponer una dirección visual propia —portada, ritmo, fondos, jerarquías y recursos gráficos— conservando el ADN de marca y la lógica narrativa.

Conservar de ese sistema:

- portada con una promesa o tensión concreta;
- recorrido visible entre las ideas de la pieza;
- variedad de layouts sin perder consistencia;
- ejemplos funcionales, comparaciones o demostraciones;
- uso de proyectos reales cuando aporten prueba;
- cierre oscuro con un único CTA accionable;
- archivos SVG editables y exportaciones PNG en 1080×1350.

Evitar:

- repetir la misma secuencia de layouts entre publicaciones;
- usar siempre la misma portada, barra de progreso o composición de CTA;
- diferenciar piezas únicamente mediante cambios de color;
- convertir el sistema visual en una plantilla rígida.

No es obligatorio repetir siempre seis pasos ni los mismos componentes. La referencia define el estándar de claridad, ritmo y profundidad visual, no una estructura rígida.

## Reels

- Duración objetivo: 15–30 segundos.
- Los casos de éxito pueden llegar a 35 segundos si cada escena aporta información nueva.
- Mostrar el gancho durante los primeros 1–2 segundos.
- Evitar introducciones de marca antes del mensaje.
- Acompañar cada título con una anotación breve que explique el beneficio, el problema o la consecuencia.
- Mantener escenas breves, contraste alto y cambios visuales frecuentes pero coherentes.
- Diseñar para comprenderse sin audio; voz, música y efectos son complementarios.
- Cerrar con un CTA único durante el tiempo suficiente para leerlo.

## CTA oficiales

- Conversión comercial principal: `Escribinos WEB por DM →` en `@nextlvl.ok`.
- WhatsApp: `3571327923`, como alternativa cuando la conversación inmediata sea central.
- Web: `nextlvl.com.ar`, para validar oferta, proceso y trabajos realizados.

No combinar los tres canales en la misma pieza. Elegir uno según el objetivo. Consultar el circuito, enlace precargado y atribución en [COMMERCIAL_OPERATIONS.md](COMMERCIAL_OPERATIONS.md#circuito-de-contacto).

## Lemas oficiales

- `Desarrollo web a medida.`
- `Llevamos tu marca al siguiente nivel.`
- `¿Querés llevar tu negocio al siguiente nivel?`

Usar como máximo uno por pieza para evitar repetición y conservar impacto.

## Control de calidad

- Fuente y pesos correctos.
- Logo oficial, no reconstruido.
- Sin etiquetas innecesarias sobre títulos.
- Márgenes y saltos revisados.
- CTA oficial y consistente.
- Sin datos dudosos.
- Exportación en dimensiones exactas.
- Lectura probada a tamaño móvil.
