# Patrones de contenido social

Seleccionar un patrón según objetivo, complejidad y evidencia. Variar el orden o combinar patrones cuando mejore la comprensión.

## Selector de formato

| Necesidad | Formato probable | Riesgo a controlar |
|---|---|---|
| Explicar una idea con progresión | Carrusel | Exceso de slides o texto |
| Mostrar cambio, proceso o demostración | Reel | Ritmo sin contenido |
| Comunicar una idea autónoma | Post | Mensaje demasiado amplio |
| Conversar, sondear o secuenciar el día | Stories | Fragmentación sin cierre |
| Profundizar una serie | Mezcla coordinada | Repetir el mismo argumento |

## Carruseles

Secuencia base: `hook → interés → desarrollo → valor → cierre → CTA`.

Variantes útiles:

- Diagnóstico: síntoma → causas → criterio → primer paso.
- Decisión: tensión → opciones → comparación → recomendación.
- Proceso: resultado → etapas → puntos de control → acción.
- Mito/reencuadre: creencia → límite → nueva lectura → aplicación.
- Caso: problema → decisión → ejecución → resultado comprobable.

Asignar una función a cada slide. Eliminar cualquier slide cuya ausencia no cambie el recorrido.

## Reels

- Abrir con tensión, resultado o pregunta reconocible.
- Hacer visible la idea central en los primeros segundos.
- Introducir cambios visuales cuando cambia la información, no por cronómetro.
- Diseñar para comprensión sin audio.
- Cerrar con síntesis y un CTA legible.

Patrones:

- Problema → consecuencia → corrección.
- Antes → decisión → después.
- Pregunta → tres criterios → recomendación.
- Demostración → explicación → aplicación.
- Lista breve con progresión, no ítems intercambiables.

## Stories

- Apertura: contexto inmediato.
- Participación: pregunta, encuesta o elección con propósito.
- Desarrollo: respuesta, criterio o prueba.
- Cierre: conclusión y siguiente paso.

No usar interacción como adorno. Explicar qué decisión ayudará a tomar.

## Posts individuales

Usar cuando una sola afirmación puede entenderse y recordarse sin secuencia. Mantener un mensaje dominante, un apoyo breve y un CTA opcional.

## Mezcla editorial

Al planificar varias piezas, equilibrar:

- Pilares y etapas del funnel.
- Profundidad y facilidad de consumo.
- Educación, prueba, conversación y acción.
- Temas nuevos y continuidades justificadas.

No fijar porcentajes ni frecuencia sin datos, capacidad de producción y horizonte temporal.

## Señales de repetición

- Mismo argumento con un título distinto.
- Misma secuencia narrativa en piezas consecutivas.
- Mismo beneficio y CTA sin cambio de etapa o audiencia.
- Misma metáfora o recurso visual como única diferencia.
- Serie que agrega volumen pero no cobertura estratégica.
