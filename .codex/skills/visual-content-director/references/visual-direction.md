# Método de dirección visual

Usar estas heurísticas para convertir un mensaje en decisiones observables.

## Jerarquía

Ordenar antes de diseñar:

1. Dominante: idea que debe reconocerse primero.
2. Apoyo: contexto necesario para interpretarla.
3. Prueba o detalle: información que sostiene la idea.
4. Navegación: número, progreso o continuidad.
5. CTA: siguiente acción, visible pero subordinada al mensaje hasta el cierre.

No usar peso, tamaño, color y posición máximos en todos los niveles.

## Gestalt y composición

- Proximidad: agrupar elementos que cumplen una misma función.
- Similitud: repetir estilos para indicar categoría o comportamiento.
- Continuidad: guiar la mirada entre unidades y hacia el siguiente paso.
- Cierre: permitir que formas incompletas simplifiquen sin generar ambigüedad.
- Figura/fondo: asegurar separación suficiente del elemento dominante.

Usar repetición para construir sistema y una ruptura deliberada para señalar cambio o énfasis.

## Grids

Elegir según contenido:

- Una columna: afirmación fuerte o lectura lineal.
- Dos columnas: comparación, antes/después o texto/imagen.
- Modular: lista, pasos, tarjetas o múltiples pruebas.
- Axial: recorrido, proceso o relación entre nodos.

Mantener alineaciones compartidas. Romper el grid sólo si mejora jerarquía o continuidad.

## Densidad

Evaluar:

- Cantidad de ideas, no sólo caracteres.
- Número de niveles tipográficos.
- Longitud de línea y tiempo disponible.
- Contraste entre bloques activos y whitespace.
- Carga acumulada en una secuencia.

Si hay más de una idea principal, dividir, simplificar o cambiar el formato. No comprimir hasta perder legibilidad.

## Relación texto/imagen

Asignar a la imagen una función explícita:

- Demostrar.
- Comparar.
- Contextualizar.
- Explicar un mecanismo.
- Aportar prueba.
- Crear una pausa rítmica.

Eliminar imágenes puramente decorativas si compiten con el mensaje.

## Continuidad en carruseles

- Mantener constantes suficientes: márgenes, familia tipográfica, navegación y lógica cromática.
- Variar composición según la función de cada slide.
- Usar dirección, escala, numeración o formas para anticipar continuidad.
- Reservar el mayor cambio visual para un giro narrativo o el cierre.

## Ritmo en reels

- Hacer coincidir cambios visuales con unidades de significado.
- Alternar densidad, escala, movimiento y pausa.
- Mantener títulos y notas legibles sin audio.
- Dejar el CTA el tiempo necesario para leer y actuar.

## Mobile-first

- Evaluar a escala real de teléfono, no sólo en lienzo grande.
- Mantener texto esencial fuera de controles y bordes.
- Favorecer líneas cortas, contraste suficiente y objetivos táctiles claros.
- Recomponer entre feed y story; no estirar.
- Probar portada, slide más denso y cierre como mínimo.

## Señales de una dirección débil

- El concepto podría servir para cualquier tema.
- Todos los elementos compiten por atención.
- La variedad depende sólo del color.
- El sistema repite una plantilla aunque cambie la idea.
- La lectura requiere zoom o conocimiento previo.
- El CTA aparece sin una ruta visual que lo prepare.
