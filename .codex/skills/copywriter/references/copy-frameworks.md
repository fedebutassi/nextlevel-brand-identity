# Frameworks de copy

Elegir el mínimo patrón que haga avanzar la lectura. Si una frase directa funciona, no usar framework.

## Selector

| Situación | Patrón | Cuidado |
|---|---|---|
| Audiencia fría y recorrido completo | AIDA | No inflar deseo ni alargar la introducción |
| Problema reconocido y solución concreta | PAS | No dramatizar ni inventar dolor |
| Transformación demostrable | BAB | No prometer un después sin evidencia |
| Headline útil y específica | 4U | Urgencia sólo si es real |
| Explicación funcional | Problema-solución | No presentar la oferta antes de entender el problema |
| Producto o servicio complejo | Beneficio-prueba | Mantener el vínculo entre característica y resultado |
| Caso o experiencia breve | Storytelling | Usar conflicto y cambio reales |

## AIDA

- Atención: abrir con una tensión, resultado o pregunta relevante.
- Interés: mostrar por qué importa en el contexto de la audiencia.
- Deseo: conectar la propuesta con un beneficio demostrable.
- Acción: ofrecer un siguiente paso proporcional.

Omitir etapas cuando ya están resueltas por el contexto.

## PAS

- Problema: nombrarlo de forma reconocible.
- Agitación: explicar consecuencia o fricción sin manipular.
- Solución: presentar criterio, acción u oferta.

No usar para temas sensibles ni cuando la agitación agregue ansiedad sin utilidad.

## BAB

- Antes: situación actual documentada.
- Después: progreso realista y verificable.
- Puente: mecanismo o decisión que permite avanzar.

Si no hay evidencia del “después”, formularlo como posibilidad, no como resultado garantizado.

## 4U para titulares

Evaluar, sin exigir las cuatro:

- Useful: ofrece una utilidad clara.
- Urgent: existe una razón temporal real.
- Unique: presenta un ángulo específico, no una superioridad vacía.
- Ultra-specific: delimita tema, audiencia o resultado.

## Beneficio con prueba

Estructura: `característica o decisión → efecto funcional → beneficio relevante → prueba`.

No saltar de una característica a un resultado comercial si el vínculo no está documentado.

## Hooks

- Pregunta que la audiencia realmente se haría.
- Contraste entre creencia y criterio.
- Consecuencia concreta de una decisión.
- Resultado o aprendizaje comprobable.
- Escena o detalle que abre una historia.

Evitar “No vas a creer”, falsa urgencia, secretos inexistentes y promesas que el cuerpo no entrega.

## CTA

Formular `verbo + acción + destino o beneficio inmediato`. Mantener un CTA principal y ajustar el compromiso a la etapa: guardar o explorar antes de consultar o comprar cuando la audiencia aún no tiene suficiente contexto.

## Cuándo escribir sin framework

- Microcopy operativo.
- Mensaje institucional corto ya definido.
- Caption cuyo recorrido surge naturalmente de la idea.
- Comunicación donde la estructura haría sonar el texto mecánico.
